# 계열 G 천문 키워드 사전 (사전 등록, 2026-11-02)

세 사료(고려사 천문지·고려사절요·승정원일기)에서 천문 기사를 고르고 건수를 세는 정규식이다. `src/build_articles_ext.py` 의 `ASTRO_PATTERNS` 가 구현이고 이 문서는 사람이 읽는 사본이다. 1.1 의 실록 키워드(`src/extract_keywords.py`)와 같은 식을 쓰는 항목은 그대로 두었고, 1.2 에서 더한 것만 아래에 표시했다. 결과를 보고 식을 고치지 않는다. 고치면 판을 올리고 두 판을 함께 싣는다.

|---|---|---|---|

**선택 규칙.** 고려사 천문지는 장 전체가 천문 기록이므로 전부 넣는다(4,568건). 절요와 승정원일기는 solar_eclipse · lunar_eclipse · comet · guest_star · venus_daytime · meteor · appulse · sunspot 중 하나 이상에 걸린 기사만 넣는다. halo · aurora_cand · venus_any 만 걸린 기사는 넣지 않는다.

**날짜 처리와 표지(`date_flag`).**

| 값 | 뜻 |
|---|---|
| (빈칸) | 국편 날짜를 그대로 씀(고려사는 국편 양력=율리우스력, 절요·승정원일기는 음력을 `korean_lunar_calendar` 로 변환) |
| ganji_mismatch | 국편 양력에서 계산한 일진이 국편 일간지와 다름(현재 0건 — 아래 보정으로 흡수) |
| nikh_solar_corrected | 국편 음력 + 일간지 + 달력 라이브러리가 일치하고 국편 양력만 다름 → 양력을 라이브러리 값으로 바꾸고 원래 값을 `solar_note`(`nikh:…`)에 남김. 1건(`kr_047_0010_0020_0150_0300`, 고종 36년 4월 朔 일식: 국편 1246-05-14 → 1249-05-14) |
| day_from_ganji | 절요의 월 단위 날짜에 본문 첫 구절의 일진을 더해 일을 복원(18건). 그 달 1일의 일진에서 30일 이내여야 한다 |
| day_unknown | 월까지만 있음 |
| before_1000 | 절요 1000년 이전 기사는 라이브러리 범위 밖이라 양력 없음 |
| no_date | 국편 날짜 없음(자리표시 9999 포함) |

**달력 라이브러리 검증(부산물).** 고려사 천문지에서 국편 음력·양력·일간지가 다 있는 1000년 이후 4,436건을 `korean_lunar_calendar` 로 변환해 국편 율리우스력 양력과 비교하면 4,435건이 같고, 다른 1건이 위의 국편 오기다. 즉 이 라이브러리는 1000~1392 고려 역일에서도 국편 역일과 일치한다(국편이 같은 연력표를 썼을 가능성이 크므로 독립 검증은 아니다 — 15 §2 의 안영숙 2009 대조가 그 몫이다).
