# 승정원일기 날씨 칸 — 토큰 사전과 날 단위 판정 규칙 (사전 등록 R1, 2026-11-02)

계열 F 의 어떤 수치도 계산하기 전에 고정한 규칙이다. 구현은 `src/weather_tokens.py` 이고 이 문서는 사람이 읽는 사본이다. 이후 규칙을 바꾸면 R2 로 번호를 올리고 두 판의 결과를 함께 싣는다. 외부 데이터셋(Lyu 외 2024, Lee 외 2024)과의 일치율을 높이려고 규칙을 손대지 않는다.

## 1. 입력

국사편찬위원회 승정원일기 XML 의 날 요소(`level4 type="일"`) 안 `front/description/weather` 문자열. 2026-11-02 실측: 날 노드 104,074 · 날씨 문자열 있는 날 102,397 · 서로 다른 문자열 896종 · 글자 종류 234.

## 2. 토큰

최장 일치로 왼쪽부터 자른다. 구두점·괄호(` ,。、·〈〉[]()○◆`)는 버린다. 사전에 없는 글자는 「잔여」로 보고하고, 빌드 검사는 **896종 전부에서 잔여 0** 을 요구한다(2026-11-02 통과).

## 3. 날 단위 판정

| 변수 | 규칙 |
|---|---|
| kind | blank(`-` 또는 빈 칸) / note_only(날씨 부류 토큰이 하나도 없음 — 日食·燼餘 만 적힌 날, 결측으로 취급) / weather |
| clear_any · cloudy_any · rain_any · snow_any · hail_any · fog_any · thunder_any · wind_any · frost_any | 그 부류 토큰이 문자열 어디에든 있으면 참. 시간대·或·乍 무관 |
| precip_any | rain ∨ snow ∨ hail |
| clear_only | 날씨 부류가 clear 뿐 |
| mixed | 날씨 부류(바람·안개·천둥·서리 제외)가 둘 이상이거나 或·乍 가 있음 |
| provenance_note · astro_note | 해당 토큰 존재 |

2026-11-02 전수 적용(102,397일): weather 101,793 · blank 579 · note_only 25. clear_only 76,489(74.7%) · rain_any 12,787 · snow_any 1,504 · hail 23 · fog 62 · thunder 39 · wind 462 · frost 6 · mixed 7,056. 이 수치는 규칙 검사용 집계이며 지표 F1 은 단계 2 에서 왕대·월별로 다시 낸다.
